Description: Understand how neural networks learn and make predictions.

Topics to Cover:
- Perceptrons and activation functions (ReLU, Sigmoid, Tanh)
- Forward propagation
- Backpropagation algorithm
- Loss functions (MSE, Cross-Entropy)
- Optimizers (SGD, Adam, RMSprop)
- Batch normalization and dropout

Hands-on Exercises:
- Build a Neural Network from Scratch: Implement feedforward and backpropagation in NumPy
- XOR Problem: Solve the classic XOR problem with a simple neural network
- MNIST with Custom NN: Build a digit classifier without frameworks
