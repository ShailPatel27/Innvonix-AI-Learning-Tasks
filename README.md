# Python and AI Learning

A hands-on collection of lessons, notebooks, and projects, progressing from Python fundamentals to machine learning and AI applications.

## Modules

### Basic Python
- Variables, data types, and control flow
- Functions, comprehensions, decorators, and generators
- OOP, methods, file handling, and practice projects

### Advanced Python
- Advanced OOP, modular programming, and error handling
- Multithreading and multiprocessing
- Database operations

### Asynchronous Python
- Async programming with `asyncio`
- Creating and working with tasks

### Machine Learning and Deep Learning
- Programming and math foundations; data manipulation and visualization
- Regression, classification, and unsupervised learning
- Neural networks: FNNs, CNNs, and RNNs

### LangChain
- Language models, embeddings, prompts, and structured output
- Chains, runnables, document loading, and text splitting
- Vector stores, retrievers, RAG, tools, and agents

### Model Context Protocol (MCP)
- MCP fundamentals, protocol concepts, and primitives
- Building MCP servers and connecting clients
- Example weather tool; standard I/O and server-sent event transports

### FastAPI
- Build APIs with path and query parameters, request bodies, and response models
- Handle validation, errors, dependencies, forms, and file uploads
- Explore middleware, background tasks, and a small CRUD API

### LangGraph and Agentic AI
- Pydantic validation and LangGraph fundamentals
- Agentic chatbots, MCP-connected agents, debugging, and monitoring
- Multi-agent systems and RAG pipelines
- Advanced retrieval, Typesense, hallucination reduction, and multimodal PDF/image search

### Streamlit
- Build interactive Python apps with text and input widgets
- Organize pages with sidebars, columns, and forms
- Manage session state and display tables and charts
- Mini-project: Study Progress Tracker with CSV import/export and progress charts

## Getting started

Requires Python 3.11 or newer. From the repository root, install dependencies with:

```bash
uv sync
```

Some examples require API credentials or configuration for external services.
